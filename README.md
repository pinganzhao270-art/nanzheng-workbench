# 南政工作台 v1.2.0

当前版本已将应用主入口改为 Supabase 工作台业务模块：首页、收款账号、订单、付款、代付、团队成员和经营统计。账号/订单/付款/代付列表读取现有 `workbench_*` 表；店主可维护记录，团队成员按数据库策略只读。

## 重要边界
- 店主通过 `store_admins.user_id` 授权，成员通过 `store_team_members.user_id` 授权。
- 状态更新只修改工作台记录，不代表真实支付、到账、充值、提现或资金划转。
- 团队邀请/开户、消息、客服、公告、实时监控、支付渠道回调和真实资金处理尚未完成，不能视为已交付。
- 参考 APK 是 Flutter AOT 发布包，本项目独立重建，不声称恢复或复制其原始 Dart 源码。

## 构建
构建直接使用仓库根目录 `App.js`，不再用隐藏压缩文件覆盖应用入口。版本 1.2.0，Android versionCode 3。构建成功不等于全部业务验收通过；仍需真机、权限和完整业务流程验收。
