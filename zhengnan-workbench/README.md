# 政南工作台

独立新项目，不依赖旧版南政工作台源码。Android/iOS 使用 Expo + React Native。

## 当前阶段
- 独立应用标识：`com.zhengnan.workbench`
- 应用显示名称：政南工作台
- 版本：1.0.0 / versionCode 1
- 已建立首页、账号、订单、付款、代付、消息、客服、我的等页面入口及基础交互。
- 参考融通工作台的业务域：余额、流水统计、收款账号/通道、订单、付款/代付、充值/提现、团队、消息、公告、客服、报表和安全设置。

## 重要说明
本项目为独立重建，不复制第三方 APK 的受版权保护源码、私有接口或密钥。当前业务列表为空态；真实余额、订单、资金操作、客服和团队管理必须接入经授权的后端服务后才能启用。不会用演示金额冒充真实资金。

## 构建
在本目录运行 `npm install`，然后 `npx expo export --platform android`。Android 原生包需使用 EAS Build 或配置好的 Android 构建环境。
