# 南政工作台完整复刻功能验收清单

本清单是新版实现与验收依据。目标是依据用户提供的融通工作台 APK、截图及静态分析结果，重建可操作的等价业务体验；不声称恢复了闭源 APK 的原始 Dart 源码。凡涉及真实资金的动作，只有在南政自有服务端、权限校验、支付渠道和审计接口接通后才能执行。

## 全局交互与状态

- 主导航：首页、账号、订单、付款、代付、更多；底部消息/工作台/客服/我的入口按参考图逐项核对。
- 所有列表统一支持首次加载、下拉刷新、分页/加载更多、空数据、搜索无结果、网络错误、权限不足、操作提交中、成功/失败反馈。
- 所有二级页支持返回、保留必要筛选条件、表单草稿、重复提交保护和离开未保存提示。
- 所有写操作必须显示确认弹窗；危险操作要求二次确认；服务端失败时保留输入并给出可理解错误。
- 列表筛选需支持状态、类型、时间范围、关键词；筛选条件可清空；筛选结果与计数同步。
- 金额统一使用 CNY 展示规则，明确区分可用余额、冻结金额、待结算金额和累计统计；不得把演示值显示成真实资金。

## 首页 / 余额工作台

子页面与入口：
- 余额详情、财务明细/流水、今日/昨日流水统计。
- 转分、下发/提现申请、USDT 充值、代付充值、充值记录。
- 公告/系统通知、账号状态与安全设置。

按钮与状态：
- 刷新：重新拉取余额、统计和公告；显示刷新中、成功时间或失败提示。
- 余额显隐：仅切换金额遮罩，不改变余额。
- 转分/下发/充值：打开独立表单；校验金额、限额、目标账户、备注；预览费用和到账金额；二次确认后提交后端；显示处理中/待审核/成功/失败/未知结果。
- 统计卡：进入对应时间范围和业务类型的流水列表。
- 账号启停：确认后调用权限受控接口，失败时回滚开关。
- USDT 充值：展示收款信息、网络/链类型和订单状态；地址/二维码由可信后端提供；提交 TXID 后进入验证中，不能本地伪造到账。

## 账号 / 收款账号与通道

子页面：
- 收款类型/通道分类列表、账号列表、账号详情、创建账号、编辑账号。
- 账号授权、二维码查看/上传/替换/删除。
- 批量编辑、批量启用/停用、功能指引。
- 通道详情、费率/限额配置、通道状态与筛选。

按钮与状态：
- 分类卡片进入对应账号列表；列表可按启用状态、通道、关键词筛选。
- 新增/编辑：表单字段校验，取消时提示未保存；保存显示提交中和服务端结果。
- 授权：展示授权范围和有效期，确认后请求服务端；过期/拒绝状态可重新授权。
- 二维码：预览、上传进度、替换确认、删除确认；文件类型/大小校验。
- 批量编辑：先多选账号，再选择字段和值，预览影响范围，确认执行并展示逐项成功/失败摘要。
- 一键关闭/开启：明确影响数量，二次确认，逐项反馈，不静默改变。
- 通道费率/限额：编辑草稿、校验范围、保存后刷新列表；无权限时禁用并说明原因。

## 订单

子页面：
- 订单列表、订单筛选、订单详情、订单规则/接单设置。
- 接单队列、掉单队列、个人排名/任务详情（仅当服务端提供相应能力）。
- 订单安全密码设置/验证。

按钮与状态：
- 列表按待处理/处理中/成功/失败/关闭等服务端状态筛选，支持订单号、金额、时间搜索。
- 订单卡片进入详情，显示订单信息、时间线、关联账号/通道、处理记录。
- 接单/确认/关闭等动作按角色和状态控制；确认弹窗展示金额及不可逆提示；提交后锁定按钮防重复。
- 订单规则页可编辑接单开关、额度/限额等配置，保存前预览并确认。
- 展开全部/收起全部控制列表内容；筛选弹窗支持重置和应用。
- 订单密码只用于敏感操作的二次验证，密码错误、锁定、网络异常均明确提示。

## 付款

子页面：
- 付款任务列表、付款详情、付款信息/支付指引、凭证上传、付款记录。
- 付款规则、支付类型说明、异常/申诉记录。

按钮与状态：
- 列表按待付款/处理中/待审核/成功/失败/超时筛选。
- 详情展示收款方、金额、截止时间、支付方式、订单状态和处理日志。
- 查看二维码/支付信息前校验当前任务状态与用户权限。
- 上传凭证支持选择、预览、替换、删除、上传进度和失败重试；提交前确认。
- 提交付款凭证后进入待核验，不可直接标记真实付款成功；只有可信服务端回调/审核结果可更新最终状态。
- 超时、重复付款风险、凭证不清晰等情况给出明确异常处理入口。

## 代付

子页面：
- 代付任务列表、代付详情、支付二维码/支付指引。
- 代付审核/处理表单、回单上传、审核结果、代付规则。
- 代付记录与失败/异常详情。

按钮与状态：
- 按待处理/处理中/待审核/成功/失败/已取消筛选。
- 详情展示申请信息、收款账户、金额、手续费、时间限制和状态时间线。
- 处理前检查角色、额度、账户状态、订单锁和任务状态；二次确认。
- 二维码仅展示服务端返回的有效支付信息。
- 回单上传支持预览、重传、删除确认、审核中状态。
- 审核通过/驳回必须记录操作者、时间、原因；失败时不伪造成功。
- 幂等键/重复提交保护，网络超时显示“结果待确认”，刷新服务端状态后再决定下一步。

## 更多 / 团队 / 消息 / 客服 / 监控

- 更多：监控页、费率、佣金保护、支付类型指引、充值规则、付款规则、代付规则、账号功能指南、系统公告、个人设置。
- 团队：成员列表、成员详情、邀请/开户、编辑资料、启停、角色权限、操作记录；只有店主管理员可管理成员，团队成员按授权范围使用。
- 消息：会话列表、会话详情、已读同步、文本/图片/视频/音频发送、发送中/失败重试。
- 客服：连接状态、会话拉取、消息发送、附件上传、断线重连和失败提示。
- 监控：服务状态、通道状态、最近更新时间、异常告警；仅展示后端真实监控数据。

## 数据与安全验收

- 所有列表、详情和统计最终以南政 Supabase/自有 API 返回为准；每个查询都必须按当前用户身份和角色执行 RLS/服务端权限检查。
- 关键操作写入审计记录：操作者、对象、动作、请求 ID、时间、结果和失败原因。
- 余额、充值、提现/下发、转分、付款、代付不能由客户端直接改数；必须服务端事务、幂等、额度校验及支付渠道确认。
- 未接通服务端的页面可以提供清楚标识的交互演示，但不得显示“交易成功”或伪造余额变化。
- 上线验收逐项检查：页面可达、按钮有动作、表单校验、弹窗确认、筛选生效、状态流转、刷新一致、异常可恢复、权限正确、数据不串用户。
